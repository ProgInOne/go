<Section kind="objectives">
- `fmt.Println`으로 원하는 값을 출력할 수 있어요.
- 여러 문장이 어떤 순서로 실행되는지 예측할 수 있어요.
</Section>

<Section kind="prerequisites" />

<Section kind="intro">
프로그램이 무엇을 하고 있는지 알려면 **결과를 눈으로 확인**할 방법이 필요합니다.
Go에서는 <ConceptLink to="go.basics.println">fmt.Println</ConceptLink>이 그 역할을 합니다.
</Section>

<Section kind="principle">
`main` 함수 안의 문장은 위에서 아래로 **한 문장씩** 실행됩니다.

<CompareTable columns={["코드", "결과"]}>
<Row label="숫자">`fmt.Println(1)` | `1`</Row>
<Row label="문자열">`fmt.Println("안녕")` | `안녕`</Row>
</CompareTable>
</Section>

<Section kind="examples">
```go
package main

import "fmt"

func main() {
	fmt.Println("안녕하세요")
	fmt.Println(1 + 2)
}
```
</Section>

<Section kind="walkthrough">
첫 줄은 문자열을 그대로 출력하고, 둘째 줄은 `1 + 2`를 계산한 `3`을 출력합니다.
</Section>

<Section kind="pitfalls">
<Pitfall misconception="go.mc.println-is-return">
<Wrong>출력한 값은 어딘가에 저장된다.</Wrong>
<Actual>화면에 보여 줄 뿐, 값을 저장하지 않는다.</Actual>
<Right>값을 나중에 쓰려면 변수에 담아야 한다.</Right>
</Pitfall>
</Section>

</Callout>
</Section>
