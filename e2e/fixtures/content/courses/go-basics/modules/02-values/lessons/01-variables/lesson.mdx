<Section kind="objectives">
- `var`와 `const`로 이름을 선언할 수 있어요.
- `const` 상수에 다시 대입할 수 없다는 것을 설명할 수 있어요.
</Section>

<Section kind="prerequisites" />

<Section kind="intro">
값을 여러 번 쓰려면 이름을 붙여 두어야 합니다. 이름 붙은 값을 **변수**라고 합니다.
</Section>

<Section kind="principle">
<ConceptLink to="go.vars.var">var</ConceptLink>로 선언한 변수는 나중에 다른 값을 넣을 수 있고,
<ConceptLink to="go.vars.const">const</ConceptLink>로 선언한 상수는 처음 값을 바꿀 수 없습니다.
</Section>

<Section kind="examples">
```go
var count = 1
count = 2
fmt.Println(count)
```
</Section>

<Section kind="walkthrough">
`count`에 처음 `1`을 담고, 다음 줄에서 `2`를 다시 대입했으므로 `2`가 출력됩니다.
</Section>

<Section kind="pitfalls">
<Pitfall misconception="go.mc.const-reassign">
<Wrong>const 상수에도 나중에 다른 값을 대입할 수 있다.</Wrong>
<Actual>const 상수에 다시 대입하면 컴파일 오류가 난다.</Actual>
<Right>값을 바꿀 이름은 var로 선언한다.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
<Callout kind="tip" title="바뀌지 않는 값은 const">
바꿀 일이 없는 값은 `const`로 선언하면 실수로 바꾸는 일을 막을 수 있어요.
</Callout>
</Section>

<Section kind="summary">
- `var`는 다시 대입할 수 있는 변수를 선언합니다.
- `const`는 다시 대입할 수 없는 상수를 선언합니다.
</Section>
